# Career Quest

Полный README для жюри находится в [корне репозитория](../README.md): описание проблемы, функции, архитектура, технологии, данные, сценарий проверки и ограничения.

## Быстрый запуск из этой папки

```bash
python3 server.py
```

На Windows можно использовать `python server.py`. Требуется Python 3.10+, сторонние пакеты не нужны.

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Логины `employee` и `hr` с отдельными паролями выводятся в терминале сервера. Пароли по умолчанию меняются при перезапуске. Для повторного запуска сначала остановите предыдущий процесс через Ctrl+C.

В «Лаборатории развития» можно сравнить активности под бюджет времени и смоделировать до трёх шагов без изменения профиля. Для E0028 на свежем наборе System Design и публичное выступление дают сценарий на 11 часов: 70,8% → 77,1% → 85,4% готовности.

## Проверки
